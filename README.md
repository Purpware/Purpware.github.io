# Purpware.github.io

Static portfolio site hosted with GitHub Pages.

Live URL: https://Purpware.github.io/

## Deploy

This folder is the published site. After making changes, commit and push to the `main` branch of the `Purpware/Purpware.github.io` repository. GitHub Pages will publish automatically.

Local preview:

```powershell
$env:SITE_ROOT = "C:\Users\ghost\OneDrive\Desktop\Purpware.github.io"
& "C:\Program Files\nodejs\node.exe" "D:\Ev erything from the desktop\DESKTOP STUFF\axon-portfolio-source\serve-static.mjs"
```

Then open http://localhost:8080/
